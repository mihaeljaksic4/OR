# README.md

## Opis skupa podataka

Ovaj skup podataka sadrži informacije o televizijskim serijama, uključujući nazive, kreatore, žanrove, glavne uloge, ocjene, godine prikazivanja, broj sezona i epizoda, trajanje epizoda i zemlje podrijetla.

## Metapodaci

- **Licenca:** Creative Commons CC0 1.0 Universal
- **Autor:** Mihael Jakšić
- **Verzija skupa podataka:** 1.0
- **Jezik podataka:** Hrvatski
- **Opis atributa:**
  - **ID:** Jedinstveni identifikator za svaku seriju
  - **Naziv:** Naziv serije
  - **Kreator:** Ime i prezime kreatora serije
  - **Žanr:** Žanr serije
  - **Glavna uloga:** Ime i prezime glumca u glavnoj ulozi
  - **Ocjena:** Prosječna ocjena serije na IMDb-u (maksimalna ocjena je 10)
  - **Godina početka:** Godina početka prikazivanja serije
  - **Godina završetka:** Godina završetka prikazivanja serije
  - **Broj sezona:** Ukupan broj sezona serije
  - **Broj epizoda:** Ukupan broj epizoda serije
  - **Prosječno trajanje epizode:** Prosječno trajanje jedne epizode u minutama
  - **Zemlja:** Zemlja podrijetla serije
